## What Was Built

Phase 3 Wave 1 focused on **per-session model override** — allowing users to create sessions with different models via `/new <name> --model <model>`, while maintaining a global default.

### Features Delivered

1. **Type System** — Added `model?: string` to `SessionEntry` (Noble Six)
2. **Registry & Persistence** — Extended registry schema to store per-session model (Carter)
3. **CLI Commands** — `/new --model` flag + model display in `/list` (Kat)
4. **Tests** — 13 new TDD test cases covering model override workflows (Jun)
5. **Documentation** — Complete README.md with setup guide and feature reference (Kat)

### Architecture Designs (P1/P2 Features)

Noble Six finalized designs for:
- **SDK Crash Auto-Recovery** (P1) — Error-triggered restart with exponential backoff
- **HUD Footer** (P2) — Session name + model appended to replies
- **Two-Tier Permissions** (P2) — Configurable permission policy via env var
- **Pairing Codes** (P2) — One-time 6-digit code on startup

Designs documented in `.squad/decisions/inbox/noble six-phase3-designs.md`.
