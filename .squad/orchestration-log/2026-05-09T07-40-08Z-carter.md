## Summary

Investigated whether GitHub Copilot CLI extension API can replace `--ui-server` as the bridge between live desktop CLI sessions and the Reach daemon.

**Outcome:** ✅ **CONFIRMED.** Extension surface is production-ready.

## Key Findings

- **Extension API:** `@github/copilot-sdk@0.2.2` exports `joinSession()`, `session.send()`, `session.on()`
- **Architecture:** Extension runs as forked Node child of CLI with full network access via JSON-RPC/stdio
- **Capability:** Can inject prompts, stream events, register slash commands, async background code, full network access
- **Discovery:** No port-discovery gap — extension is in CLI's stdio tree; daemon communicates via named pipe / loopback socket
- **Attach:** Bidirectional `/attach` to live desktop sessions becomes possible
- **Setup:** Single install to user extensions dir; can be automated in `reach install` 
- **Trade-off:** Reach gains per-user CLI extension install footprint in addition to daemon
