## Decision Summary

- **ADR-1:** Copilot CLI Extension API for session attach (no port discovery, push-based registration)
- **ADR-2:** Push-based discovery with `listSessions()` fallback for dormant sessions
- **ADR-3:** Single named pipe `\\.\pipe\reach-bridge`, multiplexed by sessionId, JSON-Lines framing
- **ADR-4:** Extension crash = session unreachable (no auto-recovery); user manually restarts CLI
- **ADR-5:** Daemon service account runs as logged-in user (not LocalSystem); fixes `LookupAccountName failed: 1332` bug
- **ADR-6:** Extension reconnect policy uses exponential backoff (base 1s, ceiling 300s, never give up while CLI alive)
- **ADR-7:** Heartbeat protocol uses both pipe teardown detection (<1s) and ping/pong (30s interval, 5s pong timeout, 15s grace = 50s worst-case)
