## Changes Delivered

### Decision: `session.event` Shape (Documented)

**Artifact:** `.squad/decisions/inbox/jun-day2-session-event-shape.md`

**Choice:** Field name `payload: unknown` (not `data`, not `Record<string, unknown>`)

**Rationale:**
- Matches ADR-8 field name exactly
- `unknown` enforces narrowing at callsites (intentional for deferred types)
- Non-breaking refinement path: when ADR-9 locks a specific payload shape, narrowing `unknown` to concrete type is safe

**Alternatives rejected:**
- `data?: unknown` — diverges from ADR-8 naming; optional implies daemon may omit
- `payload: Record<string, unknown>` — over-constrains; non-object payloads should be allowed
- `payload: { kind: string; ... }` — pre-assumes discriminator; ADR-8 doesn't lock payload shape
