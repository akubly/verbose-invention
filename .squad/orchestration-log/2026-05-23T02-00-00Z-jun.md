## Key Behavioral Insight: No-Timeout Safety Invariant

**The invariant:** A pending `promptUserForPermission()` resolves ONLY via:
1. User tap (Approve/Deny button in Telegram)
2. Session disconnect → AbortSignal fires
3. Daemon restart → map cleared

**Keystone test:** C2-01 — "Session disconnect → AbortSignal fires **within one event loop turn**"  
This single test is the load-bearing proof that the no-timeout safety invariant holds.
