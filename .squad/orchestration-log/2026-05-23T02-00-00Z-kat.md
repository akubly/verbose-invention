## Technical Insights

### 1. `raceAbortSignals()` Helper

Implemented local helper instead of `AbortSignal.any()` to support Node 20.0–20.2. Can be replaced once floor is pinned ≥ 20.3.

### 2. Self-Cleaning Listener Pattern

`session.disconnected` handler removes all three permission listeners in one go (`try/finally` guard) to prevent emitter accumulation on reconnects. Avoids need for explicit `dispose()` method; disconnect is the protocol's only session-end signal.

### 3. `exactOptionalPropertyTypes` Workaround

Conditional spread pattern in `BridgeSessionFactory._makeSession()` handles optional `allowAlwaysStore` property when `exactOptionalPropertyTypes: true` is set.

### 4. Pre-Aborted Signal Handling

After `bot.api.sendMessage()`, promptly check `signal.aborted` before registering listener — already-fired abort events won't trigger listener callbacks.
