4. **removeKnownCwd behavior** — No-op on missing alias; error semantics deferred to command layer
5. **KnownCwd shape** — alias, path (normalized), addedAt, lastUsedAt (optional)
6. **Backward compatibility** — knownCwds optional on ReachConfig; helpers treat absent as []
