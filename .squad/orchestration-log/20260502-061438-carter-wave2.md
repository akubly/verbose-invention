## Responsibilities Completed

1. **splitForTelegram Implementation** (`src/relay/messageSplitter.ts`)
   - Pure function: `splitForTelegram(text: string, opts?: SplitOptions): string[]`
   - Contract locked by Jun's 21 tests (all GREEN ✅)

2. **Boundary Preference Order** (D1)
   - Split on paragraph boundaries (`\n\n`) first
   - Fall back to line boundaries (`\n`)
   - Then whitespace (word boundaries)
   - Last resort: hard cut (unbreakable content)

3. **Code Block Protection** (D2)
   - Never split mid-block
   - Split at line boundaries inside block
   - Re-open/close with balanced fences (` ```lang ` open, ` ``` ` close)
   - Sub-chunk preserves language tag from original block

4. **Spanning Block Detection** (D3)
   - Explicit handling when code block starts within window but extends beyond
   - If plain text precedes block, split at best boundary before block starts
   - If block starts at position zero, apply `splitCodeBlock` directly

5. **Footer Overhead Management** (D4)
   - Reserve `footer.length + 2` (for `\n\n`) from last chunk budget
   - Footer appended post-split (not passed into algorithm)
   - Prevents footer from causing overflow

6. **Two-Pass Numbering** (D5)
   - First pass: split to get total count
   - Second pass: prepend `[n/total]\n` to each chunk (only when total > 1)
   - No `[1/1]` prefix on single-chunk responses (cleaner UX)

7. **Multi-Chunk Relay Integration** (D6)
   - First chunk: replaces placeholder via `safeEdit()` (maintains thread positioning)
   - Subsequent chunks: new messages via `ctx.reply()` with `message_thread_id`
   - 100ms delay between sends (within Telegram rate limits ~30 msg/s)

## Key Design Decisions

| Decision | Rationale |
|----------|-----------|
| Edit first, reply rest | Cleaner UX; placeholder replaced, no flash |
| 100ms delay | Stays within rate limits; prevents retry storms |
| Two-pass numbering | Accurate total on any digit count; cleaner on single-chunk |
| Reserve footer room | Prevents last chunk overflow |
| Line-boundary inside code | Maintains readability; balanced fences restore context |
